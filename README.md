# Milestone 2: Accessibility and Visual Design

## 1. Accessibility Fixes

- I added a skip link to all three pages so keyboard users can jump directly to the main content.
- I added visible keyboard focus outlines to help users see which link or element they are selecting.
- I improved the active navigation color to make the text easier to read.
- I added proper labels to the contact form fields so users know what information to enter.
- I added a fieldset and legend to group the contact reason options.
- I added error messages and accessible error states to help users correct mistakes when filling out the form.

## 2. Gestalt Principles

- **Proximity:** I grouped related project cards together using CSS Grid and consistent spacing.
- **Similarity:** I used the same purple color palette, fonts, borders, and navigation style across all three pages to make the website look consistent.

## 4. Accessibility Testing

I tested my Home, Projects, and About pages using WAVE and checked my text and background color combinations using the WAVE Contrast Checker because the WebAIM contrast checker said I needed permission. The checker reported that my color combinations passed the contrast requirements.

- Home: 10/10
