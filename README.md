# Milestone 2: Accessibility and Visual Design

## 1. Accessibility Fixes

- I added a skip link to all three pages so keyboard users can skip the navigation and go directly to the main content.
- I added visible keyboard focus outlines to links, buttons, and the main content area so users can see which element they are selecting.
- I added an active navigation style to show users which page they are currently viewing.
- I added proper labels to the contact form fields so users know what information to enter.
- I added a fieldset and legend to group the contact reason options and make them easier to understand.
- I added error messages and accessible error states to the contact form so users can see and correct mistakes.
- I added form validation to check that required fields are completed and that the email address is valid.
- I added reduced-motion support so users who prefer less animation can use the website more comfortably.
- I added descriptive alternative text to the track image so screen reader users can understand what the image shows.

## 2. Gestalt Principles

- **Proximity:** I grouped related project cards and page content together using CSS Grid and consistent spacing. This helps users understand which information belongs together.
- **Similarity:** I used the same purple color palette, fonts, borders, cards, and navigation style across all three pages. This makes the website look consistent and helps users recognize similar elements.
